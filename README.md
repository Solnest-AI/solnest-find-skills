# Find Skills

A Solnest AI Skool tool for Claude Code.

Ask Claude "is there a skill for this?" and it searches the open skills library (skills.sh) for a ready-made skill that does the job. It shows you the best matches with how many people use each one and who made it, and installs the one you pick.

## What you need

- Claude Code (desktop app or terminal), logged in.
- Node.js. Setup checks for it and helps you install it if it is missing. It is free.
- No accounts, no API keys, no cost beyond your normal Claude plan.

## Set it up in 3 steps

1. Copy this page's link.
2. Paste it into Claude Code and say: **set this up**
3. Try it. Say: **find a skill for making PDFs**

## Good to know

- Updates install themselves. Once a day, when Claude Code starts, the tool quietly moves to the newest release. You never have to ask.
- An update never wipes your own changes. Any change you asked Claude to make to how this tool works, and every skill you installed with it, stays exactly as it is.
- Want it to work differently? Just tell Claude ("only show me skills with more than 5,000 installs"). It remembers.
- The skills it finds are made by other people. Claude checks how popular and trusted a skill is before it suggests one, and it asks you before it installs anything.

## Credit

The skill itself is the open-source `find-skills` skill from Vercel's [skills](https://github.com/vercel-labs/skills) project, used under the MIT license. The license is kept in `skill/find-skills/LICENSE`. Solnest AI added the one-step setup and the automatic updates.
